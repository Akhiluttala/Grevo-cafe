# Grevo Cafe — Luxury Website Demo

A responsive static HTML/CSS/JavaScript concept website inspired by the Grevo Cafe reference screenshots and business details supplied in this conversation.

## Files
- `index.html` — website content
- `styles.css` — responsive design and styling
- `script.js` — mobile navigation and dynamic copyright year
- `assets/` — cropped reference images

## Preview
Extract the ZIP, then double-click `index.html` to open it in a modern browser. No installation or build step is required. Internet access is needed for the Google Fonts; system fonts will be used if unavailable.

## Important before presenting/publishing
- This is a concept demo, not an official Grevo Cafe website.
- Confirm current menu, prices, opening hours, phone number, booking and ordering process with the owner.
- The reference images were cropped from Google Maps screenshots supplied by the user and may include artifacts. Replace them with original, owner-approved photos before launch.
- Obtain permission to use the café logo, photos and any review quotations.
- Confirm the final brand colours, social media accounts and business details.
- Add approved privacy/legal pages before adding forms, analytics or online ordering.

Menu cards are visual categories rather than a confirmed complete menu. The directions link opens a Google Maps search for Grevo Cafe.
